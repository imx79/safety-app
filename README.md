# 🛡️ نظام إدارة الأمن والسلامة

نظام شامل لإدارة قسم الأمن والسلامة في المنشأة، يتضمن لوحة تحكم متكاملة، إدارة مستخدمين بصلاحيات مخصصة، إدارة أقسام، وقوالب تقارير قابلة للتخصيص الكامل.

## ✨ المميزات

- 🔐 **نظام تسجيل دخول آمن** مع تشفير كلمات المرور (bcrypt)
- 👥 **إدارة المستخدمين** مع 5 أدوار جاهزة (Admin, Manager, Editor, Viewer, Operator)
- 🔑 **صلاحيات مرنة** يمكن تخصيصها لكل مستخدم بشكل مستقل
- 🏢 **إدارة الأقسام** مع دعم الأقسام الفرعية
- 📝 **محرر قوالب بصري** لتصميم نماذج التقارير حسب احتياجات المنشأة
- 📋 **إدارة التقارير**: حوادث، جولات تفتيشية، تدريب، معدات السلامة
- 📊 **لوحة تحكم تفاعلية** مع رسوم بيانية ومؤشرات أداء (KPIs)
- ⭐ **تقييم الموظفين** ومتابعة أدائهم
- 📁 **إدارة الملفات** ورفع المرفقات
- 🌐 **دعم لغتين** (عربي/إنجليزي) مع RTL/LTR
- 🎨 **تخصيص شامل** للألوان، الشعار، أسماء المنشأة، رؤوس وذيول التقارير
- 📜 **سجل تدقيق كامل** لجميع الإجراءات
- 🖨️ **طباعة التقارير** بتصميم احترافي

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js v16 أو أحدث
- npm

### الخطوات

```bash
# 1. الانتقال إلى مجلد المشروع
cd safety-app

# 2. تثبيت التبعيات
npm install

# 3. تهيئة قاعدة البيانات (تنشئ تلقائياً عند أول تشغيل)
npm run init-db

# 4. تشغيل الخادم
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

### الحساب الافتراضي
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

⚠️ **مهم:** غيّر كلمة المرور فور تسجيل الدخول الأول من قسم الإعدادات → الأمان.

## 🔐 الأدوار والصلاحيات

| الدور | الوصف |
|------|------|
| **Admin** | تحكم كامل بالنظام - جميع الصلاحيات |
| **Manager** | إدارة قسم وعرض الإحصاءات واعتماد التقارير |
| **Editor** | إنشاء وتعديل التقارير |
| **Viewer** | عرض التقارير والطباعة فقط |
| **Operator** | تعبئة التقارير وطباعتها |

يمكن للأدمن تخصيص صلاحيات إضافية لأي مستخدم بشكل فردي عبر زر 🔐 في صفحة المستخدمين.

## 🎨 تخصيص النماذج لمطابقة منشأتك

1. اذهب إلى **القوالب** → **➕ قالب جديد** (أو اضغط 🎨 على قالب موجود)
2. أضف الحقول المطلوبة من الشريط الجانبي (نصوص، تواريخ، قوائم منسدلة، إلخ)
3. عدّل خصائص كل حقل (الاسم، الإلزامية، الخيارات)
4. وسّع قسم **"تخصيص الرأس والذيل"** لإضافة:
   - شعار المنشأة
   - اسم المنشأة وشعارها
   - حقول التوقيع والاعتماد
   - أي HTML مخصص

## ⚙️ إعدادات النظام الشاملة

من قسم الإعدادات يمكنك التحكم بـ:
- اسم الموقع والمنشأة (عربي/إنجليزي)
- اللغة الافتراضية وصيغة التاريخ
- ألوان النظام (الأساسي والمميز)
- مسار الشعار
- مهلة الجلسة
- تفعيل/تعطيل التسجيل الذاتي
- سجل التدقيق
- تغيير كلمة المرور

## 🔒 ملاحظات أمنية

- كلمات المرور مشفرة بـ bcrypt
- الجلسات تنتهي بعد 8 ساعات
- جميع الإجراءات الحساسة مسجلة في سجل التدقيق
- التحقق من الصلاحيات على مستوى الخادم لكل طلب

في الإنتاج: غيّر `SESSION_SECRET` في متغيرات البيئة، واستخدم HTTPS، وضع التطبيق خلف Reverse Proxy.
